# Lamia Islam Mim — Portfolio

Personal portfolio of Lamia Islam Mim, Computer Science & Engineering graduate from North South University, Dhaka.

**Live:** https://lamia-mim.github.io/

Featured work: Trenzy (e-commerce), ElderEase (social impact), a data-driven study of elder abuse in Bangladesh, [Token Tax](https://lamia-mim.github.io/token-tax/), a study and live tool on how AI tokenizers treat Bangla, and [Paper Physics](https://lamia-mim.github.io/paper-physics/), which animates any physics diagram on the picture itself and explains each step.

Plain HTML, CSS and JavaScript. No build step.
